# Reader fonts

Geist (Vercel) and Newsreader (Production Type), SIL Open Font License 1.1; licenses included. Public Google Fonts CSS2 distribution. Self-hosted variable WOFF2 Latin and Latin-ext subsets; no runtime external requests. Geist normal (100–900); Newsreader normal and italic (400–700), optical size fixed at 24 for reading text, avoiding the unused optical-size axis. All faces use `font-display: swap`.
